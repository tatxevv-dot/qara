# Zone

Футбольная аналитика: топ-5 лиг (АПЛ, Ла Лига, Серия А, Бундеслига, Лига 1) и Лига чемпионов.

- Фронтенд: статический HTML/CSS/JS (GitHub Pages), стиль Apple, логика FotMob.
- Данные: Supabase (Postgres, read-only RLS для anon), обновление через Edge Function `zone-sync` + pg_cron каждые 10 минут.
- Источник: публичные данные ESPN. xG и рейтинг игроков — собственная модель Zone.

Разделы: матчи по дням (live), лиги (таблица, дома/в гостях, форма, xPTS, игроки, команды, xG-аналитика), матч (события, статистика, составы на поле, карта ударов, личные встречи), команда, игрок (перцентили, карта ударов, матчи), статистика, сравнение игроков.
